# Skyline Shuffler

**Skyline Shuffler** is a 3D hyper-casual puzzle game built in **Unity** using **C#**, where players use a crane-hook mechanic to move color-coded buildings onto their matching plots.

The project focuses on **gameplay programming**, **puzzle-solving algorithms**, **level validation**, **game-state management**, and **in-game systems**, developed during my Unity Game Development Internship at **evoDART Studios**.

---

## 🎮 Project Overview

- **Genre:** 3D Hyper-Casual Puzzle
- **Engine:** Unity
- **Language:** C#
- **Platform:** Android
- **Core Mechanic:** Crane-hook building placement
- **Game Type:** Level-based Puzzle

The primary goal of the project was to create a lightweight mobile puzzle experience with structured level progression, intuitive gameplay, and reliable puzzle-state handling.
